## 개요

### 워크플로우

OPIc Helper는 OPIc 스피킹 테스트를 준비하기 위한 AI 기반 학습 플랫폼입니다.

- **AI 평가:** 답변 분석 및 피드백 제공
- **STT:** 음성 인식 (WebGPU 기반)
- **숙달도 추적:** 사용자 진행 상황 모니터링
- **개인화:** 사용자 수준과 흥미에 맞는 문제 추천

### 주요 기능

1. **로그인** - Google OAuth로 간편하게 로그인
2. **서베이** - 흥미 있는 주제 선택 (6~12개)
3. **연습** - 음성으로 답변하고 실시간 피드백 받기
4. **롤플레이** - AI와 대화 연습
5. **대시보드** - 학습 통계 및 진행 상황 확인

## 시작하기

### 1. 회원가입

OPIc Helper는 Google OAuth를 사용합니다.

**단계:**
1. 로그인 페이지에서 "Google로 시작하기" 클릭
2. Google 계정으로 로그인
3. OPIc Helper 사용 허용 확인

**참고:**
- 기존 Google 계정을 그대로 사용하세요
- 별도의 회원가입은 필요 없습니다

---

### 2. 브라우저 요구사항

OPIc Helper의 STT 기능을 사용하려면:

**필수:**
- Google Chrome 113+ 또는 Microsoft Edge 113+
- HTTPS 연결 (localhost 제외)

**권한:**
- 마이크 접근 권한 (첫 음성 녹음 시 요청)

**참고:**
- Chrome 다운로드: https://www.google.com/chrome/
- 첫 실행 시 ~100MB 모델 다운로드 (캐시됨)

## 서베이

### 개요

서베이에서 흥미 있는 주제를 선택하면, 관련 문제가 출제됩니다.

### 서베이 완성

**단계:**
1. 로그인 후 서베이 페이지로 이동
2. 각 카테고리에서 원하는 항목 선택
   - 주거 (1개): 아파트, 빌라, 주택 등
   - 여가 (2개): 카페, 영화관, 쇼핑 등
   - 취미 (2개): 음악, 독서, 요리 등
   - 운동 (2개): 수영, 요가, 헬스 등
   - 여행 (2~5개): 국내여행, 해외여행 등
3. "서베이 완료" 클릭

**제약사항:**
- 최소 6개, 최대 12개 항목 선택
- 서베이는 한 번만 완성할 수 있습니다
- 수정은 연습 페이지에서 가능합니다

## 연습하기

### 개요

연습 페이지에서 OPIc 문제를 연습할 수 있습니다.

### 문제 구조

```
┌─────────────────────────────────┐
│     문제 정보                 │
│   - 주제: 카페           │
│   - 유형: 경험            │
│   - 난이도: IM2           │
├─────────────────────────────────┤
│                             │
│     문제                     │
│  카페에서 기억에 남는     │
│  경험에 대해 말해주세요.    │
│                             │
├─────────────────────────────────┤
│                             │
│     학습 팁                  │
│   • 도입 - 상황 설정       │
│   • 전개 - 구체적 경험     │
│   • 마무리 - 느낀 점       │
│                             │
└─────────────────────────────────┘
```

### 답변 단계

1. **문제 확인**
   - 주제, 유형, 난이도 확인
   - 학습 팁 참고

2. **녹음 시작**
   - "녹음 시작" 버튼 클릭
   - 90초 안에 답변
   - 녹음 중에는 상황 설명

3. **답변**

4. **녹음 중지**
   - "녹음 중지" 버튼 클릭
   - 자동으로 음성 → 텍스트 변환

### 음성 인식

**과정:**
1. 녹음된 음성을 Whisper AI로 분석
2. 텍스트로 변환
3. 단어별 신뢰도(confidence) 계산
4. FastAPI 서버로 전송 (향후 기능)

**결과 표시:**
- **전체 발음 점수** (0-100)
- **인식된 텍스트**
- **단어별 분석** (신뢰도 표시)

### AI 평가

**평가 기준 (5가지):**
1. **발화량** - 문장 수, 단어 수
2. **문법** - 시제 일관성, 수 일치
3. **어휘** - 다양성, 고급 표현
4. **구조** - 도입-전개-결론
5. **발음** - 발음 정확도

**피드백:**
- 잘한 점: 강점
- 부족한 점: 개선 필요 사항
- 개선 방법: 구체적인 조언
- 모범 답안: 예시 답변

### 피드백 후

**작업:**
- **다음 문제** - 계속 연습
- **문제 건너뛰기** - 다른 문제로 이동
- **피드백 확인** - 상세 분석 확인

**자동 저장:**
- 답변 텍스트
- AI 평가 결과
- 숙달도 업데이트

## 대시보드

### 개요

대시보드에서 학습 진행 상황을 한눈에 확인할 수 있습니다.

### 표시 항목

1. **사용자 정보**
   - 이름
   - 현재 수준: IM2
   - 목표 수준: IH

2. **통계**
   - 총 시도 횟수
   - 숙달 문제 수
   - 평균 점수
   - 레벨 업그레이드 횟수

3. **약한 주제**
   - 낮은 점수를 받은 주제 목록
   - 우선적으로 연습 권장

4. **최근 피드백**
   - 최근 5개 피드백 기록
   - 문제, 평가 수준, 점수

### 숙달도

```
미시도: ━━━━━━━━━━━ 35
시도: ▓▓▓▓▓▓▓▓▓▓▓▓▓ 10
부분숙달: ⚫⚫⚫⚫⚫▓▓▓▓▓▓▓▓ 3
숙달: ⚫⚫⚫⚫⚫⚫⚫⚫⚫⚫ 2
```

- **미시도:** 시도하지 않음
- **시도:** 시도 중
- **부분숙달:** 부분 숙달 (2회 이상 시도, 점수 향상)
- **숙달:** 3회 연속으로 점수 달성

## 롤플레이

### 개요

AI와 실시간 대화 연습을 할 수 있습니다.

### 롤플레이 유형

**11번 문제:** 상황극 전화
**12번 문제:** 예약/문의

### 대화 방식

1. **시나리오** 시작
2. **AI 역할:** 극장 직원, 공항 직원 등
3. **사용자 역할:** 고객, 예약자
4. **대화 진행:** 3~4번 질문/응답
5. **종료 및 평가**

### 예시 대화

```
사용자: 안녕하세요, 극장 표를 예약하고 싶어요.
AI: 네, 어떤 영화를 보시겠습니까?
사용자: 아바타 2 표세요.
AI: 네, 몇 시 표에 예약드릴까요?
사용자: 오후 3시 표로 예약해 주세요.
AI: 알겠습니다. 이름이 어떻게 되시나요?
AI: 예약되었습니다. 감사합니다!
```

## 문제 해결

### 음성 인식 문제

**문제:** 텍스트가 제대로 인식되지 않음

**해결책:**
1. 마이크가 꽉혀 있는지 확인
2. 조용하게 말하기
3. 주변 소음 줄이기
4. 브라우저에서 마이크 권한 확인

### WebGPU 문제

**문제:** "WebGPU를 지원하지 않습니다" 메시지

**해결책:**
1. Chrome 버전 확인 (113+ 필요)
2. HTTPS 연결 확인
3. 다른 브라우저에서 시도 (Edge)
4. 하드웨어 가속 확인

### 모델 로딩 문제

**문제:** 모델이 로딩되지 않음

**해결책:**
1. 인터넷 연결 확인
2. 캐시 비우기
3. 브라우저 재시작
4. 다른 브라우저에서 시도

## FAQ

### 질문: 서베이를 수정하고 싶어요

**답변:**
서베이는 수정이 불가능합니다. 관리자에게 문의하세요.

---

### 질문: 현재 수준을 어떻게 알 수 있나요?

**답변:**
대시보드 페이지에서 현재 수준을 확인할 수 있습니다. AI 평가 결과에 따라 자동으로 업데이트됩니다.

---

### 질문: 언제 수준이 오르나요?

**답변:**
수준은 자동으로 업데이트되며, 정확한 기준은 공개되지 않습니다. 일반적으로 3회 연속으로 높은 점수를 받으면 상승합니다.

---

### 질문: 음성 녹음은 어디서 저장되나요?

**답변:**
녹음된 음성은 브라우저에서만 처리되며, 서버에는 텍스트만 전송됩니다. 프라이버시가 보호됩니다.

---

### 질문: AI 평가는 얼마나 정확한가요?

**답변:**
AI 평가는 OPIc 전문가가 설계한 5가지 기준을 기반으로 하며, 실제 OPIc 평가와 유사한 경향을 가지고 있습니다. 그러나 완벽하지 않을 수 있습니다.
