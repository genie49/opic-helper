## 핵심 설계 결정

### 1. OPIc 시험 구조 반영

- **문제 난이도 무시**: OPIc은 같은 주제/유형의 문제가 난이도와 관계없이 동일
- **레벨은 평가에서 결정**: 문제가 아닌 답변 평가 기준으로 등급 판정
- **AI 평가 레벨**: 자기 평가 대신 AI가 평가한 레벨 사용

### 2. 롤플레이 처리

- **일방향 독백**: OPIc 롤플레이는 대화형이 아님
- **별도 페이지 불필요**: 연습 페이지에서 문제 유형으로 처리
- **API 단순화**: 롤플레이 전용 API 제거

### 3. 클라이언트 사이드 STT

- **프라이버시**: 음성 파일 서버 업로드 없음
- **비용 절감**: STT API 비용 $0
- **WebGPU 필수**: Chrome 113+ 필요
